                 -> Generate -> copy.
            4. Set as Windows env var:

                 [Environment]::SetEnvironmentVariable(
                   "HUGGINGFACE_HUB_TOKEN", "hf_<paste>", "User"
                 )

            5. Add to .env as well:
                 HUGGINGFACE_HUB_TOKEN=hf_<paste>

  Verify:   .\venv\Scripts\python.exe -c "from huggingface_hub import whoami; print(whoami())"
