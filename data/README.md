# Data

The competition dataset is **not committed** to this repository — per Kaggle terms and size constraints.

## Downloading

The dataset is hosted on Kaggle: <https://www.kaggle.com/competitions/fathomnet-2026/data>.

```bash
pip install kaggle
kaggle competitions download -c fathomnet-2026 -p data/raw
unzip data/raw/fathomnet-2026.zip -d data/raw
```

After unzipping, the expected layout is:

```
data/
├── raw/
│   ├── train/                 # ~6,500 train images
│   ├── test/                  # ~1,425 test images
│   ├── train_dataset.json     # COCO-format train annotations
│   └── test_dataset.json      # COCO-format test image manifest
├── processed/                 # generated by scripts/coco_to_yolo.py
└── folds/                     # generated by scripts/make_yolo_fold.py
```

## Dataset shape

- **Train:** 6,463 images, 32 classes, COCO-format annotations
- **Test:** 1,425 images, predictions evaluated on mAP@[.50:.95]
- **Domain split (key insight):** train is 100% NOAA + SOI imagery; test is 100% MBARI VARS framegrabs. See [`../README.md`](../README.md) for the institutional-disjoint analysis that drove the modeling strategy.

## Preprocessing

After download, convert annotations and build folds:

```bash
python scripts/coco_to_yolo.py
python scripts/make_yolo_fold.py
```

These produce `data/processed/` (YOLO-format labels) and `data/folds/` (5-fold split YAMLs) consumed by the training scripts.
