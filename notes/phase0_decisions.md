## Dataset shape

- Train images: **6463** | annotations: **22225** | categories: **32**
- Test images: **1425** (annotations empty by design — FLAG 5)
- Median annotations / image: **2.0**
- Median categories  / image: **1.0**

## Class imbalance

- Imbalance ratio (max/min instances): **818:1**
- Classes with `< 100` instances: **14**
- Classes with `< 50`  instances: **9**
- Top 3:    urchin (5723), bony fish (3069), sea fan (3026)
- Bottom 3: isopod (28), sea squirt (17), sea slug (7)

## PU severity

- Single-category-image rate: **62.5%**  →  band: **HIGH**

## Object size

- Objects with max-side `< 64 px`: **5.1%**
- Objects with max-side `< 32 px`: **0.4%**
- Objects with relative area `< 1%`: **67.2%**
- Recommended `imgsz`: **640** (Phase 4 EXP 4.1 will compare against 1280 — see plan tension note below)
- SAHI priority: **OPTIONAL for high-res inference, MANDATORY for the 14% low-res (720×486) test subset**

  Resolution-conditional routing happens in Phase 7 (I.2): detect image dims at test
  time, run SAHI with small slices for low-res images, plain inference for high-res.
  The "OPTIONAL" label above only applies to the >86% high-res test subset.

## Plan tension noted (resolved in master plan)

- **imgsz**: this EDA recommends 640 (based on training object pixel sizes);
  master plan v5 says "1280 baseline, but verify" (line 532) because of the
  test-resolution shift. **Resolution: run Phase 4 EXP 4.1 as a 640-vs-1280
  ablation** — both numbers are needed. EDA looked at training objects;
  plan accounted for test-time low-res images. Final answer comes from
  empirical CV mAP, not from either of these two priors.

- **SAHI**: see "Object size" section above for the resolution-conditional
  resolution.
